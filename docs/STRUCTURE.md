# Project Structure

```
sales-customer-insights-dashboard/
│
├── 📂 data/
│   └── dataset.xlsx                          # Cleaned source data (Excel)
│
├── 📂 sql/
│   └── sql_queries.sql                       # Annotated SQL queries (5 sections)
│
├── 📂 reports/
│   └── dashboard.pbix                        # Power BI interactive dashboard
│
├── 📂 docs/
│   ├── BRD.docx                              # Business Requirements Document
│   ├── FRD.docx                              # Functional Requirements Document
│   ├── NFRD.docx                             # Non-Functional Requirements Document
│   └── STRUCTURE.md                          # This file
│
├── 📂 assets/
│   └── Advanced_Sales_Customer_Insights.png  # Dashboard preview image
│
└── README.md                                 # Project overview and usage guide
```

## Folder Descriptions

| Folder | Contents | Purpose |
|--------|----------|---------|
| `data/` | `dataset.xlsx` | Source data — cleaned and ready for SQL import or Power BI |
| `sql/` | `sql_queries.sql` | All business analysis queries, organized in 5 labeled sections |
| `reports/` | `dashboard.pbix` | The Power BI dashboard — open with Power BI Desktop |
| `docs/` | BRD, FRD, NFRD, STRUCTURE | Project documentation and requirements |
| `assets/` | `Advanced_Sales_Customer_Insights.png` | Dashboard screenshot used in the README |
